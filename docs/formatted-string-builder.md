# FormattedStringBuilder

`FormattedStringBuilder` wraps `StringBuilder` and keeps track of indentation. `AppendLine()` writes the line
terminator plus the current indentation, so whatever you write next starts in the right place.

**Namespace:** `ZCrew.Extensions.CodeAnalysis.CSharp.Text`

## API

### Indentation

```csharp
FormattedStringBuilder Indent()    // +4 spaces
FormattedStringBuilder Unindent()  // -4 spaces (throws if already at 0)
```

### Appending

```csharp
FormattedStringBuilder Append(string value)      // writes at the cursor, no indentation
FormattedStringBuilder AppendLine()              // newline + current indentation
FormattedStringBuilder AppendLine(string value)  // text + newline + current indentation
FormattedStringBuilder AppendLine(char value)    // char + newline + current indentation
```

The indentation lands after the newline, setting up the *next* write. `Append()` writes inline and adds
nothing.

### Output

```csharp
string ToString()
SourceText ToSourceText(Encoding? encoding = null)  // defaults to UTF-8
```

The usual `StringBuilder` methods (`AppendFormat`, `Insert`, `Replace`, `Clear`, and so on) are all there too.

## Extension methods

`FormattedStringBuilderExtensions` covers the boilerplate every generated file needs:

```csharp
// // <auto-generated/>
FormattedStringBuilder AppendAutoGeneratedComment()

// #nullable enable
FormattedStringBuilder AppendNullableEnable()

// #pragma warning disable 0618, 1591, 8019
FormattedStringBuilder AppendCommonPragmaDisable()

// [global::System.CodeDom.Compiler.GeneratedCode("AssemblyName", "0.0.0.0")]
FormattedStringBuilder AppendGeneratedAttribute(string assemblyName, string assemblyVersion = "0.0.0.0")

// namespace MyNamespace;  (skipped if the namespace is null or whitespace)
FormattedStringBuilder AppendFileScopedNamespaceDeclaration(string? @namespace)

// typeof(typeName)
FormattedStringBuilder AppendTypeof(string typeName)

// a raw string literal (""" ... """)
FormattedStringBuilder AppendRawString(string rawString)

// a braced, indented block; nest these like you'd nest the braces
FormattedStringBuilder AppendBlock(Action<FormattedStringBuilder> body)
```

## Example: generating a class

This is what the library's own `EmbeddedAbstractionSourceTextEmitter` does. `AppendBlock` opens the brace,
indents the body, and closes back on the opening brace's level, so nesting a method inside a class means
nesting the calls and no `Indent()`/`Unindent()` bookkeeping:

```csharp
var builder = new FormattedStringBuilder();

builder
    .AppendAutoGeneratedComment()
    .AppendNullableEnable()
    .AppendCommonPragmaDisable()
    .AppendLine()
    .AppendLine("using System.Text;")
    .AppendLine("using Microsoft.CodeAnalysis.Text;")
    .AppendLine()
    .AppendFileScopedNamespaceDeclaration("MyNamespace")
    .AppendLine()
    .AppendEmbeddedAttribute()
    .AppendGeneratedAttribute("MyGenerator")
    .AppendLine("internal static partial class FooSourceText")
    .AppendBlock(classBlock => classBlock
        .Append("public static readonly SourceText SourceText = SourceText.From(")
        .Indent()
        .AppendLine()
        .Append("\"content\",")
        .AppendLine()
        .Append("Encoding.UTF8")
        .Unindent()
        .AppendLine()
        .AppendLine(");")
        .AppendLine()
        .AppendLine("public static void AddFooDefinition(this IncrementalGeneratorPostInitializationContext context)")
        .AppendBlock(methodBlock => methodBlock
            .Append("context.AddSource(\"MyNamespace.FooSourceText.g.cs\", SourceText);")))
    .AppendLine();
```

`Indent()`/`Unindent()` are still what you want inside a block for continuation lines that have no braces of
their own, like the wrapped `SourceText.From(` arguments above.

Out comes:

```csharp
// <auto-generated/>
#nullable enable
#pragma warning disable 0618, 1591, 8019

using System.Text;
using Microsoft.CodeAnalysis.Text;

namespace MyNamespace;

[global::Microsoft.CodeAnalysis.Embedded]
[global::System.CodeDom.Compiler.GeneratedCode("MyGenerator", "0.0.0.0")]
internal static partial class FooSourceText
{
    public static readonly SourceText SourceText = SourceText.From(
        "content",
        Encoding.UTF8
    );

    public static void AddFooDefinition(this IncrementalGeneratorPostInitializationContext context)
    {
        context.AddSource("MyNamespace.FooSourceText.g.cs", SourceText);
    }
}
```

## Tips

- `Append` for same-line content, `AppendLine` when you want to move down a line.
- The header extensions (`AppendAutoGeneratedComment()`, `AppendNullableEnable()`,
  `AppendCommonPragmaDisable()`, `AppendGeneratedAttribute()`) keep every generated file's preamble the same.
- Pair every `Indent()` with an `Unindent()`. An unmatched `Unindent()` throws `InvalidOperationException`.
